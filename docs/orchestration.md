## T01 — Clio client, ingest, PDF text  (branch `task/t01-clio-ingest`)
- **Goal**: `syncMatter(matterId)` pulls all record types for one matter via GET, normalizes them to `ClioRecord`s, stores items + change events by content hash, downloads PDFs per version and stores per-page text.
- **Owned paths**: `src/lib/clio/**`, `src/lib/ingest/**`, `src/lib/pdf/**`.
- **Spec**:
  - `clioGet`: base `CLIO_BASE_URL` (append `/api/v4` if missing), bearer token from `getClioAccessToken()` (`src/lib/auth`, a stub until T07 lands; fall back to `process.env.CLIO_ACCESS_TOKEN`). Follows `meta.paging.next`, `limit=200`, `fields=` per type (copy the valid field lists from `scripts/clio_dump.py`), max 2 in flight, honors `Retry-After` and sleeps when `X-RateLimit-Remaining <= 2`. A guard throws on any method other than GET. Fixture mode: if `CLIO_FIXTURE_DIR` is set, read `<dir>/<name>.json` (same filenames as `fixtures/clio/`) instead of HTTP.
  - Normalizers for every type, per `types.ts`: html-unescape note/comm text; `bodyText` = subject + body; `drawerKey`; `sourceDate` = business date; `contentHash` = sha256 of projected fields (plus etag), never `updated_at`; contacts get `role` from the relationship description and `roleKind` from generic keywords (provider|treating|hospital|radiology|surgical|therapy|chiro → provider; adverse|defendant → adverse; insur|adjuster|administrator → insurer); expense `kind` by shape (`total == null && non_billable_total != null` → `provider_bill`); `providerContactId` by fuzzy-matching the bill filename/note against provider contact names (normalized tokens, ≥60% overlap, else null); `billFilename` parsed from the note; custom fields → `CustomFieldValue` (id like `currency-30008`).
  - Documents: `downloadDocument` GETs `documents/{id}/download.json` → follows the 303 to the signed URL **without** the Authorization header and checks the host; store the file under `data/docs/<clioId>-<versionUuid>.pdf`; skip if it already exists. `extractPdfText` uses `pdfjs-dist/legacy/build/pdf.mjs` in Node and returns per-page text.
  - `syncMatter`: upsert into `items`, write `item_events` (new/changed/deleted) when the hash differs, upsert `document_texts`. Use `getDb()` from `src/lib/db` (a stub until T04; in tests inject an in-memory better-sqlite3 db, running `src/lib/db/schema.sql`). `loadRecords`, `getDocumentText`, `getDocumentFilePath` read the DB.
- **Verify**: `npm run typecheck && npm test -- src/lib/clio src/lib/ingest src/lib/pdf` with tests covering: counts per type from `fixtures/clio`, the GET-only guard throws on POST, expense split + provider matching (each bill maps to the right fake provider), html entities unescaped, the content hash unchanged when only `updated_at` changes, `extractPdfText(fixtures/documents/bill-of-particulars-sample.pdf)` returns 3 pages with "TEAR OF THE MEDIAL MENISCUS" on page 3, and a second sync with no changes writes no events.

## T02 — Deterministic digest core  (branch `task/t02-digest-core`)
- **Goal**: `computeDeterministic()` produces every non-AI part of the `Digest` from records + `ExtractedFacts`, plus `validateRefs`, `inputSetHash` and `diffSince`. All math is in code.
- **Owned paths**: `src/lib/digest/**`.
- **Spec** (see `docs/research/stories/01`, `03` for the reasoning; use generic rules only):
  - KPIs: `case_value` (custom field of currency type whose name matches /case value/i, else `facts.caseValue`; `range.cap` = the BI per-person limit); `coverage` (layers from `facts.coverage`; UM/UIM adds only the amount above BI; exhausted layers are excluded; `conflicts` from `facts.conflicts`); `firm_spend` = sum of `Expense.kind==='firm'`; `specials` = sum of provider bills (cross-check against a custom field matching /specials/i and warn on mismatch); `last_client_contact` = latest communication where the client is a sender OR a receiver (phone counts; also notes whose text says the client called), with `daysAgo`; `next_deadline` = earliest open task or future calendar entry.
  - `valueWaterfall`: effective coverage cap → minus liens (`facts.liens`) → minus firm costs → "Before attorney fees".
  - `providerBills`: group provider bills by `providerContactId`; `servicesThrough` parsed from the note when present.
  - Action board: overdue = open task with `dueAt < now`; upcoming = open task or calendar entry within 30 days; `waitingOn` = the task names or is assigned to a contact (match relationship contact names in the task name; "By medical provider:"/"By client:" prefixes are a generic convention fallback) and that contact has received outbound comms with no later reply from them; `requests` = count of those comms, `daysSilent` = since the first unanswered one. SOL tasks (`isSol`) and the matter `sol` with a past date and status complete render as `header.sol.status = 'satisfied'`, never overdue.
  - `topTen`: score = recency decay (half-life 180 days on `sourceDate`) + signal terms (generic list: limit, coverage, lien, surgery, deposition, IME, offer, demand, settlement, posture, summary) + dollar amounts present + still-open cross-references (mentioned by an open task); unique; rank 1..n; `why` left '' (AI fills it); `totalItems` = all records except custom fields.
  - `timeline`: dated events from calendar entries, notes, comms, documents and the incident custom field; `milestone` true for incident, retained, surgery, suit filed, coverage confirmed, IME, trial/conference (generic keyword rules).
  - `client`: name, initials, age from DOB, last contact, next touchpoint (next calendar entry mentioning treatment or the client).
  - `stage`: map the Clio `matter_stage` name plus evidence to `StageKey` (generic).
  - `validateRefs`: the rules in contract section 5 (unknown id → drop; quote whitespace/case/curly-quote-normalized substring of `bodyText`, or of that document page's text for page refs; page within range; dates `stated` only if in the quote). Must handle ALL-CAPS text with hard line breaks.
  - `inputSetHash` = sha256 over sorted `(drawerKey, contentHash)`; `diffSince(records, iso)` = records whose `sourceDate >= iso` as `ChangeEntry` (the "Compare since" control).
- **Verify**: `npm run typecheck && npm test -- src/lib/digest` with RED→GREEN tests on records normalized from `fixtures/clio` (write a small local normalizer helper inside your test dir if T01 isn't merged; do not import fixtures from non-test code). Expected on fixtures with `now = 2026-10-02`: firm spend 735; specials 41250; 2 overdue (the Lakeview and client tasks), the Lakeview item `waitingOn.requests = 3`; SOL `satisfied`; last client contact 2026-09-28 (Phone); a quote with different line breaks/case still verifies; an unknown id is dropped.
- **Chain**: `/ecc:orchestrate custom "ecc:tdd-guide,ecc:typescript-reviewer" "[Plan: docs/plan.md#phase-1-B] Deterministic digest: KPIs, waterfall, action board with waiting-on, code-ranked top ten, milestones, validator, change diff; Acceptance: fixture expectations pass; no LLM arithmetic"`

## T03 — AI digestion pipeline  (branch `task/t03-ai-pipeline`)
- **Goal**: `buildDigest()` turns records + document texts into a full `Digest` using Claude for extraction and synthesis only, with every ref validated and every call's cost logged. Plus the `scripts/build-digest.ts` CLI.
- **Owned paths**: `src/lib/ai/**`, `scripts/build-digest.ts`.
- **Spec**:
  - Models from env: `MODEL_EXTRACT` (default `claude-haiku-4-5`), `MODEL_SYNTH` and `MODEL_SCAN` (default `claude-sonnet-5-5`). Structured output via `output_config.format` JSON schema; no forced `tool_choice`, no prefill, no temperature. Check `stop_reason`; on refusal retry once, then degrade gracefully (empty section + `meta.warnings`).
  - `extractFacts` (Haiku): input = custom fields + notes/comms mentioning limits/coverage/value/lien. Output `LlmRef`-based facts → hydrate with `validateRefs` from `src/lib/digest` (stub until T02; mock it in tests). A numeric fact is kept only if its quote contains the number. Latest-dated source wins; older contradicting sources go to `conflicts`. Cache per (record, contentHash, extractorVersion).
  - `extractInjuries` (Sonnet): choose source documents generically: names/folders matching /bill.?of.?particulars|particulars|pleading|complaint/ first, then /medical.?records|operative|ortho|radiology/; if none, a cheap Haiku classification of each document's first page. Send per-page text with `[[PAGE n]]` markers (chunks of ≤ 25 pages); output `{name, bodyPart, status, firstDocumented, refs:[{id, quote, page}]}`; keep injuries with ≥1 verified page ref. Cache by document version.
  - `synthesize` (Sonnet, one call, ~15k tokens in): brief (3–5 claims), one-line `why` for each top-ten id (ids passed in, ranked by T02 code), open questions, client status chips; every claim needs refs, which are validated. Feed the most recent "summary/posture"-like note verbatim if one exists (generic detection).
  - `buildDigest`: `computeDeterministic` + `extractFacts` + `extractInjuries` + `synthesize`; fill `why`; set `meta` (models, `costUsd` summed from usage × price table in code, droppedRefs, warnings, builtAt). If `prev` exists and `inputSetHash` is unchanged, return `prev` with `meta.cached = true` and make zero AI calls.
  - `scripts/build-digest.ts <matterId>`: `syncMatter` → `buildDigest` → save to the `digests` table → print the summary + cost. Fixture mode works with `CLIO_FIXTURE_DIR=fixtures/clio`.
- **Verify**: `npm run typecheck && npm test -- src/lib/ai` with the SDK mocked: a hallucinated id is dropped; a numeric fact without the number in its quote is dropped; the injuries chooser picks `02-pleadings__bill-of-particulars.pdf` from the fixture documents without its name appearing in source code; an unchanged input hash → zero SDK calls; cost is summed correctly from mocked usage.
- **Chain**: `/ecc:orchestrate custom "ecc:tdd-guide,ecc:typescript-reviewer" "[Plan: docs/plan.md#phase-1-C-ai] Claude extraction, BoP injuries with page refs, single synthesis call, validated refs, cost log, cache by input hash; Acceptance: mocked tests pass; zero calls on unchanged hash"`
